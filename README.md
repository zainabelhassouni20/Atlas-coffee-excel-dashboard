# Atlas-coffee-excel-dashboard
Tableau de bord commercial interactif réalisé sous Excel pour Atlas Coffee, entreprise fictive de vente de café (Maroc, France, Espagne). 1 000 commandes reliées aux tables Clients et Produits via RECHERCHEV, RECHERCHEX et INDEX/EQUIV, analysées avec tableaux et graphiques croisés dynamiques, segments et chronologie.
